# 参考视觉系统：微信官方深色

## 资料边界

本规范只记录对用户提供的公众号文章截图和封面截图的视觉观察，不复制截图中的文章文字、账号信息、图片素材或品牌标识。截图是本地参考资料，未进入源码、测试夹具或公开发布物。

## 观察结果（Observation）

- 画面以深灰/近黑为底，正文使用低对比浅灰，避免大面积纯白造成刺眼感。
- 绿色是唯一强强调色，主要承担章节锚点、关键词、核心句和行动提示，不承担整段填色。
- 标题、章节标题、正文、说明文字之间有清楚的字号、颜色和间距层级；章节之间留出明显呼吸空间。
- 配图通常居中并保留左右留白，图片与深色背景之间有轻边框或卡片边界，图注弱化处理。
- 长文章通过编号章节、短段落和分隔线形成连续阅读节奏；图片作为论据或步骤节点插入，而不是平均塞入。
- 封面优先使用高识别度的主体和安全留白，头条封面仍遵守微信 900×383 规格。

## 设计决策（Inference → Decision）

Draftloom 新增可切换的 `official` 主题，命名为“微信官方深色”。这是从截图提炼出的视觉方向，不表示官方授权或官方模板。默认主题保持不变，避免已有稿件被静默改色。

| Token | 值 | 用途 |
| --- | --- | --- |
| `articleBackground` | `#121413` | 文章底色 |
| `surface` | `#171a19` | 预览容器与低层级背景 |
| `soft` | `#222725` | 摘要、引用、CTA 和媒体卡片 |
| `ink` | `#e8eeeb` | 标题和主文本 |
| `muted` | `#a6b0ab` | 元信息、图注和辅助说明 |
| `accent` | `#19d875` | 局部重点、章节锚点和 CTA |
| `line` | `#3a433e` | 图片、表格和分隔边界 |

## 自动排版规则

1. 正文使用安全中文字体栈，字号 15–18px，行距 1.7–2.2；官方深色主题默认左对齐。
2. 仅对识别出的重点短语、金句、核心句和章节编号进行局部加粗或色块标注；正文不整段上色。
3. 二级标题使用绿色底部锚线，三级标题使用低对比细线；标题前后的空白大于普通段落。
4. 普通正文图片自动居中，官方深色主题默认最大宽度为正文的 92%，自动带轻边框；封面保持 900×383 全宽比例。
5. 自动图片数量仍由正文篇幅和章节密度决定，视觉系统只改变呈现方式，不改变图片预算。
6. 导出 HTML 继续使用内联样式，保证复制或提交到微信后不依赖外部 CSS。

## 验证边界（Fact / Hypothesis）

- `Fact`：主题 token、图片最大宽度、局部标注和内联 HTML 可由本地测试直接验证。
- `Inference`：截图体现的视觉规律适合沉浸式、产品说明和教程类文章；不等于所有公众号题材都应使用深色主题。
- `Hypothesis`：统一的深底、绿锚点和留边图片会提升长文的扫描效率；需通过实际发布后的人工阅读反馈继续验证。
